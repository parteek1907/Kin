# UI Reference Videos & Media

Drop your reference screen recordings, animations, interaction demos, or video clips directly into this folder:

📂 `Nexus/ui-references/`

### Supported Formats
- `.mp4`
- `.mov`
- `.webm`
- `.gif`
- `.png` / `.webp`

### How It Works
1. Drag and drop any UI video or animation clip into this folder.
2. In the chat, simply mention the file name (e.g. *"I added `header-animation.mp4`"*) or ask me to inspect the new videos in this folder.
3. I will analyze the motion choreography, easing curves, layout transitions, and visual styling to implement them directly into the codebase!
