# CONDUIT — The Living Proof-of-Work & Intent Network

> **Track:** Alumni Network & Professional Connections  
> **Theme:** Building a Network, Not a Directory  
> **Architecture:** Zero-Form Artifact Ingestion, Living Force-Directed Canvas Graph, Multi-Hop Warm Routing & Zero-Login WhatsApp Bridge

---

## ⚡ The Core Philosophy: "A Network, Not A Directory"

Traditional alumni portals fail because they are static directories where users manually type unverified keywords (`React, AI, Python`) and spam alumni with cold messages that get ignored.

**CONDUIT is NOT a directory.** It replaces static profile forms, generic job boards, and cold-DM walls with an **Artifact-Verified Intent & Multi-Hop Warm Routing Network**:

1. **EXPERTISE (Zero-Form Proof-of-Work):** Automatically extracted and verified from real GitHub repositories, commits, dependencies, and research papers—never self-reported keywords.
2. **INTENT (Live Broadcast Capsules):** Time-bound, high-signal problem statements and opportunities broadcast via the Web UI or WhatsApp.
3. **OPPORTUNITIES (Multi-Hop Warm Trust Paths):** Every connection is routed through the shortest verified campus trust path (e.g., `Student -> Faculty Advisor -> Alumnus Founder`) via a 1-tap WhatsApp/Web Vouch handshake.

## 🚀 Key Features

### 1. Interactive Force-Directed Physics Graph (`<LivingNetworkCanvas />`)
- Custom 60fps HTML5 Canvas physics engine with node repulsion, link spring attraction, velocity damping, and center gravitation.
- **Color Taxonomy by Persona:**
  - **Student Builder:** Electric Cyan (`#06B6D4`)
  - **Alumni Engineer:** Neon Purple (`#8B5CF6`)
  - **Founder / YC:** Emerald Green (`#10B981`)
  - **Faculty Research Advisor:** Amber Gold (`#F59E0B`)
  - **Tech Recruiter:** Rose Pink (`#F43F5E`)
  - **Campus Institution:** Indigo Blue (`#6366F1`)
- **Node Radii:** Dynamically proportional to verified artifact impact scores (0–100).
- **Traveling Signal Particles:** Active signals continuously propagate along edges.
- **Dynamic Glow & Dimming:** Running an intent dims non-matching nodes to 15% opacity while pulsing the top 3 matches with neon rings.
- **Solid Gold Active Path:** Accepted vouches instantly transform edges into **glowing solid gold** (`#FACC15`) with particle bursts!

### 2. Live Intent Stream & Natural Language Router (`<IntentRouterPanel />`)
- Natural language query input with semantic parsing against verified repository ASTs.
- **1-Click Live Demo Presets:**
  - 🚀 **Founder Intent:** Fintech seed startup seeking student with offline-first sync + WebCrypto commits.
  - 🔬 **Faculty Intent:** Seeking 2 undergrad researchers with PyTorch multimodal OCR + RAG pipelines.
  - 💼 **Recruiter Intent:** Hiring systems engineer with real FastAPI, pgvector, and entity resolution repos.
  - 🎓 **Student Intent:** Built an AR campus routing prototype; seeking 15-min architecture review.
- Active intent capsules feed with real-time expiration timers and verified match counts.

### 3. Citation-Grounded Evidence & Warm Path Dossier (`<NodeEvidenceDrawer />`)
- **Verified Proof-of-Work Matrix:** Total commits, impact scores, language byte breakdown, and production repositories.
- **Veralon-Style Code Citations:** Pinpoints the exact commit hash and quote verifying why a student matches an intent (e.g. `Commit #a8f921c: "Implemented IndexedDB cryptographic ledger sync with zero-connectivity fallback"`).
- **Shortest Verified Trust Path Visualizer:** Visual step-by-step chain showing how trust flows through advisors and batchmates with calculated composite trust weights.
- **2-Way Action Controls:**
  - `Request 1-Tap Warm Vouch via WhatsApp`
  - `Unlock via 60-Second Technical Micro-Audit`

### 4. Interactive WhatsApp Action Bridge (`<WhatsAppBridgeDrawer />`)
- Realistically modeled smartphone chassis with dark-mode WhatsApp interface (`#111B21`).
- **Tab 1: Alumnus / Founder "Voice & Text Intent Drop":**
  - Sends simulated voice notes or text prompts without ever logging into a web portal.
  - Instantly spawns a live intent capsule on the web graph, matches campus nodes, and replies with student dossiers.
- **Tab 2: Faculty / Senior Alumnus "1-Tap Mutual Vouch Handshake":**
  - Displays incoming verification requests for faculty advisors.
  - Quick-reply buttons: `[1] Vouch & Auto-Create Intro Group` or `[2] Decline`.
  - Instantly turns the graph edge **solid glowing gold**, displays celebration alerts, and generates an automated 3-person technical briefing group!

### 5. Zero-Form Artifact Ingestion Modal (`<IngestArtifactModal />`)
- Ingests any GitHub username (e.g., `parteekgarg`, `torvalds`) via live GitHub REST API with deterministic fallback.
- Simulated terminal logs demonstrating AST parsing, commit velocity computation, and 384-d vector embeddings.
- Injects new nodes into the live physics canvas and focuses the camera onto them.

### 6. Institutional Opportunity & Skill-Gap Radar (`<InstitutionRadarModal />`)
- Macro telemetry dashboard for Deans, TBI incubators, and placement cells.
- **Real-Time Supply vs. Demand:** Compares industry demand against verified campus proof-of-work.
- **Curriculum Gap Alerts:** Identifies skills with high demand deficits and suggests targeted actions.
- **Vitality Metrics:** Tracks 88.4% warm vouch conversion rate vs. 7.2% on cold outreach.

## 🛠️ Tech Stack

- **Framework:** Next.js 14.2 (App Router), React 18, TypeScript
- **Styling:** Tailwind CSS, Glassmorphic Obsidian Design System
- **Icons:** `lucide-react`
- **Animations:** `framer-motion` & HTML5 Canvas 60fps physics simulation
- **API Endpoints:**
  - `/api/ingest`: Real GitHub REST API integration & deterministic AST extractor
  - `/api/intent-match`: Natural language intent router
  - `/api/vouch`: 1-tap warm vouch handshake & intro group generator
  - `/api/whatsapp-webhook`: WhatsApp bridge webhook handler
